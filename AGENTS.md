# Experiment conventions

- File a GitHub issue describing each experiment before creating its directory.
- Keep experiment-specific work in `experiments/<issue_number>_<short_name>/`.
- Start with a careful, reviewable plan. Distinguish planned work, executed work, and conclusions.
- Record source versions, sequence accessions, commands, parameters, checksums, and limitations for computational results. Keep large downloaded databases and temporary indexes out of Git.
- Link the issue and experiment directory from the repository README.
- The repository owner authorizes commits and pushes directly to `main`; pull requests are optional.
